# Правила поведінки

1. <span style={{ color: "red" }}>Заборонені</span> образи на адресу інших учасників, їхніх батьків чи родичів.

2. <span style={{ color: "red" }}>Заборонений</span> неприйнятний контент, що містять:
    * порнографію чи інший непристойний контент;
    * сексуальні збочення;
    * наркотичні засоби;
    * матеріали, що пропагують націоналізм, розпалюють расову, релігійну чи міжнаціональну ворожнечу;
    * політичний контент або політичні обговорення в будь-якій формі.

3. <span style={{ color: "red" }}>Заборонена</span> дезінформація, поширення неправдивих та обманлива інформація.

4. <span style={{ color: "red" }}>Заборонені</span> повідомлення, що шкодять проєкту, публікація контенту, який може негативно вплинути на рішення нових користувачів щодо купівлі товарів, або гри на проєкті.

5. <span style={{ color: "red" }}>Заборонені</span> флуд і спам. Флуд, його організація, жебракування, спам та надмірне використання CAPS заборонені.

6. Поширення будь-якого шкідливого програмного забезпечення суворо <span style={{ color: "red" }}>заборонене</span>.

7. <span style={{ color: "red" }}>Заборонена</span> реклама сторонніх ресурсів. Дозволяється рекламувати лише ресурси,
    що належать до проєкту [STEVIOUS](../../), або узгодженні з адміністрацією проєкту.

8. На сервері діють не лише внутрішні правила, а й правила спільноти [Discord](https://discord.com) та [Twitch](https://twitch.com).
    Переглянути їх можна тут:

    - [discord TOS](https://discord.com/terms/)
