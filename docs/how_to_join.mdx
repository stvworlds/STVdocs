# WIP

Щоб почати грати, спочатку прив’яжіть свій акаунт, а потім підключіться до основного сервера.

## 1. Отримайте код прив’язування

1. Зайдіть на сайт STVWorlds.
2. Натисніть кнопку **«Прив’язати акаунт»**.
3. Скопіюйте код, який з’явиться на екрані.

## 2. Прив’яжіть акаунт

1. Запустіть Minecraft і підключіться до сервера авторизації:

   ```text
   mc.stvworlds.win
   ```

2. У чаті сервера введіть команду, замінивши `<код>` на код із сайту:

   ```text
   /link <код>
   ```

3. Дочекайтеся повідомлення про успішне прив’язування акаунта.

## 3. Почніть грати

Вийдіть із сервера авторизації та підключіться до основного сервера:

```text
beta.stvworlds.win
```

Готово — тепер можна грати!
