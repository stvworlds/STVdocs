## Перевірка доступу (permit)

Якщо whitelist увімкнено, при вході на ігровий сервер перевіряється, чи гравець **має дозвіл** (permit) за UUID.

Без дозволу — кік із текстом стати гравцем на [stvworlds.win](https://stvworlds.win) або звернутися до адмінції.

Основний шлях отримати доступ — реєстрація / прив’язка через сайт і [прив’язку акаунта](/docs/features/link).

Також згадано на сторінці [Бета сервер](/docs/servers/beta).
