---
title: Чат
description: Локальний і глобальний чат на сервері
---

На сервері є два режими чату: **локальний** і **глобальний**.

## Локальний чат

Звичайне повідомлення без спецсимволу йде в **локальний чат**.

- Бачать гравці **поруч** (у радіусі близько 100 блоків) і сам автор.
- У повідомленні: нік з градієнтом і підказка «Локальний чат».
- Клац по ніку пропонує `/msg <нік>`.
- Клац по тексту — копіювання повідомлення.
- При наведенні на нік: підказка надіслати повідомлення та час гри (години).

## Глобальний чат

Повідомлення з префіксом **`!`** (наприклад `!привіт`) йде в **глобальний чат** на весь сервер.

- На початку стоїть мітка **`G`** (жовта); при наведенні — час (Київ).
- Той самий UX: клік по ніку → `/msg`, клік по тексту → копіювання.
- Підказка «Глобальний чат».

## Коротко

| Як писати | Куди йде |
| --------- | -------- |
| звичайний текст | локальний чат (поруч) |
| `!текст` | глобальний чат (весь сервер) |
