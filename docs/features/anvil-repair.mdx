---
title: Ремонт ковадла
description: Відновлення пошкодженого ковадла залізним блоком
---

На ігровому сервері можна **відремонтувати** пошкоджене ковадло без класичного крафту заново.

## Як це працює

1. Візьміть у руку **залізний блок**.
2. Натисніть **ПКМ** по **пошкодженому** або **пощербленому** ковадлу (без Shift).
3. Програють звук і іскри; **1 залізний блок** витрачається.

## Ступені ремонту

| Було | Стане |
| ---- | ----- |
| Пошкоджене ковадло | Пощерблене ковадло |
| Пощерблене ковадло | Звичайне ковадло |

Напрямок (орієнтація) блоку зберігається.
