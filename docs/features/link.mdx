Щоб грати, Minecraft-акаунт потрібно прив’язати до акаунта на сайті.

Повний сценарій: [Як приєднатися](/docs/how_to_join).

## Команда `/link`

На **лоббі**:

```text
/link <код>
```

- Код береться з веб-кабінету на [stvworlds.win](https://stvworlds.win) (розділ прив’язки акаунта).
- Успіх: «Акаунт успішно підключено».
- Типові помилки: некоректні дані, код не знайдено, доступ заборонено, немає зв’язку з API.
- Без коду показує usage: `/link [code]`.

## Короткий порядок

1. Отримати код на сайті.
2. Зайти на `mc.stvworlds.win`.
3. Виконати `/link <код>`.
4. Далі перейти на ігровий сервер (портал або `beta.stvworlds.win`).
