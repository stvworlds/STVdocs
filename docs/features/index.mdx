## Чат і спілкування

- [Чат](/docs/features/chat) — локальний і глобальний (`!`)
- [Приватні повідомлення](/docs/features/private-messages) — `/msg` (у т.ч. Discord офлайн на грі)

## Акаунт

- [Прив’язка акаунта](/docs/features/link) — `/link <код>`
- [Доступ і whitelist](/docs/features/whitelist) — permit і `/add`

## Геймплей

- [Ремонт ковадла](/docs/features/anvil-repair) — ПКМ залізним блоком

## Команди гравця

| Команда | Де | Навіщо |
| ------- | -- | ------ |
| звичайний текст | ігровий чат | локальний чат |
| `!текст` | ігровий чат | глобальний чат |
| `/msg <нік> <текст>` | гра / лоббі | приватні повідомлення |
| `/link <код>` | лоббі | прив’язка MC ↔ сайт |
| `/lobby` | ігровий сервер | повернутися в лоббі |
| `/add <нік>` | ігровий сервер | додати друга в whitelist |
