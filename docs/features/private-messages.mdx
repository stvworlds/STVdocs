Приватні повідомлення між гравцями — команда **`/msg`**.

Або: `tell`, `w`, `pm`, `t`, `message`.

Формат:

```text
/msg <гравець> <текст>
```

## На ігровому сервері (бета тощо)

- Якщо отримувач **онлайн** — повідомлення в грі у форматі «відправник ⏵ ви» / «ви ⏵ отримувач».
- Якщо **офлайн**, але акаунт **прив’язаний до Discord** — ЛС у Discord (картка з аватаром і текстом); відправнику показується статус «(офлайн)».
- Якщо офлайн і **без Discord** — помилка: гравець офлайн і не прив’язаний.
- Спонсори можуть використовувати розширене форматування тексту (MiniMessage).
- Клік по ніку / тексту: швидка відповідь і копіювання; при наведенні — смерті та години гри.

## У лоббі

- Ті самі команди.
- Працює лише для **онлайн** гравців на лоббі (без відправки в Discord).
- Такий самий формат і форматування для спонсорів.
